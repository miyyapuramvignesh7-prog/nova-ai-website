# NOVA — AI Technology Website

A modern AI-company landing page based on Group 3, Question 7 in the supplied PDF.

## Sections
- Company introduction and hero visual
- AI product cards and use cases
- Feature overview and team
- Contact call-to-action

## Files
`index.html`, `style.css`, `script.js`, `README.md`

## Run locally
Open `index.html` in your browser. The product names and company are fictional concepts for this student project.

## Deploy
Create a GitHub repository such as `nova-ai-website`, upload these files to the repository root, and enable GitHub Pages in **Settings → Pages** using the `main` branch and root folder.
